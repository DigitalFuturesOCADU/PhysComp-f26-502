## Project Overview

Create a custom controller for the classic arcade game [Pong](https://en.wikipedia.org/wiki/Pong). You will develop a novel controller that examines and pushes what is possible with this seemingly simple gameplay. Do not copy existing controller types—instead, create an object, objects, or installation that playfully explore new possibilities.

## Design Constraints

- **Do Not** copy existing game controller formats (form or inputs)
- **Do Not** use off-the-shelf buttons—you must make your own inputs
- **Do Not** base the controller on stuffed animals or weapons
- Wire your own LED Indicator using the library's `setStatusLED()` method
- Create a robust design that will hold up during gameplay

## Design Goals

- Push the limits of what can be considered a controller
- Consider craft, finish, material, mass, and scale
- Fabricate housing yourself—avoid just sticking it in an existing box
- Fully encase Arduino, wiring, battery, and sensors
- Use connection methods that allow access (don't glue it shut)
- Avoid loose and tangled wires
- Integrate an indicator LED for connection state
