## Workshop

### Physical Adjustments Demo

Live demonstration of extending wires for servos and LDRs:

- **Servo wires** — chaining jumper cables or using solid core wire from the XFab
- **Sensor wires** — soldering solid core wire to photoresistor legs

See the full guide: [Physical Adjustments — Extending Wires](PhysicalAdjustments.md)

### Work Time

Use the remaining class time to work on your prototype. This is the last full work session before the exhibition.

**Priorities:**
- Get your sensor-to-servo behavior working reliably
- Build or refine the physical mechanism attached to the servo
- Decide on material — paper, vellum, fabric, wire — and begin attaching it
- If using extended wires, solder and test them now
- Think about the full 30-minute exhibition span: does your piece need to change over time? Can it adapt to the room?

**If you are ahead**, explore:
- Adding a second servo or sensor — [Multiple Servos](MultipleServos.md), [Multiple Light Sensors](MultipleLDRs.md)
- More complex sensor-to-movement patterns — [Two LDRs + Two Servos](TwoLDRsTwoServos.md)
- Smoothing or calibration to improve reliability — [Light Sensor Guide](LightSensorGuide.md#3-smoothing--stabilizing-noisy-readings)

### Check-In

Before the end of class, brief individual check-ins on progress. Be prepared to show:

- Your current circuit and code
- The physical form you are building
- What you plan to finish before the exhibition

## Submission

- Working prototype sketch — uploaded to Canvas
- Short video (15–30 seconds) showing current state of the prototype: circuit, mechanism, and material response
- Brief written note: what works, what still needs to be done before the exhibition
