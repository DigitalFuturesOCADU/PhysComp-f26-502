Workshop Goal

Get the parts working — wire a light sensor (photoresistor) on a breadboard, read its values in the Serial Monitor, and have a servo motor respond to those values. Nothing fancy — just the foundation.

Resources
  • Arduino UNO R4 WiFi
  • Breadboard
  • Light-dependent resistor (LDR / photoresistor)
  • 10 kΩ resistor
  • Servo motor (standard hobby servo)
  • Jumper wires
  • Light Sensor to Servo — Step-by-Step Guide
  • Class 09 Notes — New components and reference links
  • Servo Movement Reference
  • Code Patterns (from Project 2)
Activity

All workshops in Project 3 have two components: a working prototype and a design sketch. Over the three workshops you will develop both.

Part 1 — Working Prototype: Control servo rotation with light

  1. Follow the Light Sensor to Servo — Step-by-Step Guide.
  2. Wire the LDR on the breadboard and confirm it reads values in the Serial Monitor.
  3. Wire the servo motor and confirm it moves to an angle you set in the code.
  4. Connect the sensor value to the servo angle using constrain() and map().
  5. Tune your lightMin / lightMax values using Serial Monitor readings from your environment.
  6. Attach an additional object to the servo horn.

Part 2 — Project Design V1

In parallel, create a drawing that shows your initial concept. Read the project brief carefully — yes, it is early, but you will improve the design each week through iteration. The drawing should note:

  1. General concept of the interaction — how is light being used to affect movement?
  2. Position of the light sensor.
  3. Servo motor(s) — what are they attached to and what do they do?
  4. Overall form factor and size — on a table, free-standing, hanging, etc.
  5. How is it being powered?

Tip: Use Serial Monitor to find your real sensor values before tuning the mapping. Don't guess — measure first, code second.
