## Overview

Today's class introduces the Tiny Screens project and the fundamentals of working with the LED Matrix and sensors.

We will cover:
- Project introduction and design constraints
- LED Matrix basics and the TinyFilmFestival library
- Creating animations with the [LED Matrix Editor](https://ledmatrix-editor.arduino.cc/)
- Distance sensor (HC-SR04) setup and reading
