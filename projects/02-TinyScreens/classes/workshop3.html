Workshop Goal

Combine sensor input with screen output into a complete interaction — starting from either an advanced sensor technique or an advanced matrix example and adding the missing half.

Activity

Part 1 — Combine Input + Output (Groups of 2–4)

Form a group of 2–4 people. Choose one starting point and add the missing half:

Starting Point What's Missing
Advanced Sensor Technique Screen output
Advanced Matrix Example Sensor input

How to think through it step by step:

  1. Identify the parameter — What value in the sketch could change? In sensor examples, it's the output visual. In matrix examples, it's the hard-coded oscillateInt() values. See Step 2: Identify the Parameter.
  2. Replace with a named variable — Give it a descriptive name (gripStrength, handSpeed). See Step 3: Replace with a Named Variable.
  3. Drive it with the missing half — If you started with a sensor example, write a draw function. If you started with a matrix example, add sensor reads and map(). See Step 4: Drive the Variable with Sensor Data.
  4. Use the read → translate → draw pattern to structure your loop().

Tip: Check the Sensor Wiring Quick Reference for pin connections, and use Serial Monitor to verify your sensor values before writing screen code.

Part 2 — Project Sketch + Plan (Individual)

Create two drawings/diagrams that describe what your device will look like and how it will work at next week's exhibition. Review the Enclosure & Fabrication section for guidance.

  1. Device sketch — A drawing or rendering of what your physical object/wearable will look like. Include the enclosure, sensor placement, and screen position.
  2. Interaction diagram — A simple diagram that shows: your chosen preposition, and how the input (sensor) will affect what appears on screen (the cause → effect relationship).
