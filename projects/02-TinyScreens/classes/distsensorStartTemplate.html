What are Ultrasonic distance sensors?

The HC-SR04 is one of the most common sensors used with Arduino. They are sensors that use ultrasonic sound to measure the distance from the sensor to the nearest object. Kind of like a bat.
Back to Top ↑

How do they work?

When a pulse is sent to the Trigger Pin the sensor emits ultrasonic sound. When the sound hits an object it bounces back toward the sensor where its microphone listens for it. The time it takes between sending the sound and hearing the bounce is then converted into a distance value.

How do they connect to Arduino?

Back to Top ↑

The sensor has 4 pins

  • VCC (Power for the Sensor) - Connect to 5V 
  • Trig (Sends the Sound) - Connects to any Digital/Analog Pin
  • Echo (Hears the Sound) - Connects to any Digital/Analog Pin
  • Gnd (Power for the Sensor) - Connect to Gnd
Back to Top ↑

Using / Modifying Jumper Wires

You can connect the sensor directly to your Arduino using 4 Pin -> Socket Jumpers from your kit. To create a lower profile, you can bend the pins on end of the jumper wires 90 degrees.

To keep the wiring tidy, the Trigger and Echo Pins are connected pins A0 (14) , A1 (15). All code examples are written assuming these connections, but you can change them to any digital or analog pin.

How is the data read within the code?

Back to Top ↑

Data Type

We are using the HCSR04 Library by Martin Sosic. This library simplifies the interaction with the sensor by creating the datatype:  UltraSonicDistanceSensor. The library was installed as part of the TinyFilmFestival Library

When creating the variable you define the Trigger Pin, Echo Pin , Max Distance. 

UltraSonicDistanceSensor sensor(triggerPin, echoPin, maxDistanceCm);

The triggerPin , echoPin correspond to the pins where it is connected. In our example 14, 15

maxDistanceCm helps prevent error readings when no objects are present. It sets a maximum value that it looks for.

So, if you were going to create a sensor object that has the connection above, with a max distance of 50cm, it would be defined:

UltraSonicDistanceSensor sensor(14, 15, 50);

Reading values + timing

The data is read from the sensor using the measureDistanceCm() method. This returns the distance to the nearest object in centimeters.

float distance = sensor.measureDistanceCm()

An important factor to keep in mind is that the sensor requires time to send/bounce/read the signal, so it is important to create a code structure to control the reading speed. All of the code examples use a simple timer that allows this without interfering with the animation timing. It is important DO NOT USE DELAY() for this, it will interfere with your other code.

Design Considerations

  • Orientation - The direction the sensor is facing changes the type of interaction with it
  • Material - Because it uses sound as the medium, objects made ofdifferent materials are read with variable levels of accuracy
  • Min / Max / Accuracty 
    • Minimum Distance : 2cm
    • Maximum Distance : 400cm
    • Accuracy : 3mm
