Workshop Goal

Explore the 3 drawing methods that can be used with your tiny Arduino screen.

Activity

Part 1 — [Install / Test the Library]

This activity will get the library installed and get you started working with the LED Matrix

  1. Install the TinyFilmFestival library through the Arduino Library Manager
  2. Open and Upload the example File -> Examples -> TinyFilmFestival -> 01_Basics -> SimpleLED 
    1. This should show up with the four corners on and a blinking square in the middle
  3. Adjust the blinkSpeed variable to see how it changes the blinking square
  4. Change the code to light up / blink different LEDs
  5. Take a PHOTO of the result

Part 2 — [Create / Play an Animation]

In this activity you will create a simple animation using the LED Matrix editor, download it, and play it on your Arduino

  1. Have a look at LED Matrix Guide . This process is covered clearly there
  2. Open and Upload the example File -> Examples -> TinyFilmFestival -> 01_Basics -> FirstAnimation
  3. You should now see an animated rectangle playing on the matrix
  4. Save this example file to your desktop
  5. Follow the steps in LED Matrix Guide  to:
    1. Create your own animation
    2. Download it to your computer as a .h file
    3. Copy it into the same folder on your Desktop where you saved the FirstAnimation example
    4. Load it into the code
    5. Upload the updated code to your board
    6. You should now see the animation you created playing on your Arduino
    7. Have a look at the API and other Examples if you want to change your animation's playback
  6. Take a short VIDEO of the result

Part 3 — [Draw Directly on the Canvas]

This activity will introduce drawing on the matrix using the built in shapes

  1. Have a look at the API for this method
  2. Open and Upload the example File -> Examples -> TinyFilmFestival -> 01_Basics -> FirstCanvas
  3. You should see a single dot moving up and down on the Matrix
  4. Consult the API and other examples and Draw your own pattern on the screen. (Can be static or animated)
  5. Take PHOTO if you created a static pattern and a VIDEO if you created an animated one
